# Changelog

## [1.2.0] - 2026-05-22

### Добавлено / Added
- Установлена новая кастомная иконка приложения.
- Добавлена возможность выпускать сборку с использованием локального ключа релиза (`release.jks`, alias: `my-release-key`).
- Проект теперь корректно собирается с `compileSdk = 34` для поддержки локальных сред и предотвращения конфликтов с версией Gradle (AGP).

### Изменено / Changed
- Обновлена версия приложения до 1.2.
- Настроена совместимость JVM-target (версия 11) для правильной работы `KotlinCompiler` внутри локальных IDE и утилиты командной строки (`compileSdk`, `targetSdk` понижены до 34 ради более высокой стабильности компиляции).
- Оптимизированы зависимости Gradle и параметры для корректного инжекта конфигурации секретов и иконок.

### Исправлено / Fixed
- Исправлена проблема с видимостью `ic_launcher`, из-за которой сборка выкидывала ошибку AAPT (не удалось найти ресурс `ic_launcher`).
- Решена ошибка с "Inconsistent JVM-target compatibility", из-за которой процесс компиляции `compileDebugKotlin` падал.
